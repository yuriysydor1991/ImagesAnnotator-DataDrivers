# Запуск доступних виконуваних файлів

Будьмо чесними щодо того, що тут є: даний проект створює динамічну бібліотеку і взагалі жодного бінарного файлу застосунку, отож запускати щось власне проектове тут нема чого. Виконуваними файлами, які таки будуються, є бінарні файли GoogleTest - юніт-тести `UTEST_*` і компонентні тести `CTEST_*` - і вони з'являються лише тоді, коли тести було увімкнено на стадії конфігурації (див. підрозділ [Вмикання юніт-тестів](/doc/sections/uk_UA/5-project-build/testing/5-3-1-enabling-unit-testing.md)). Усе решта, що ти можеш захотіти запустити, є твоєю власною програмою, злінкованою зі встановленою бібліотекою.
