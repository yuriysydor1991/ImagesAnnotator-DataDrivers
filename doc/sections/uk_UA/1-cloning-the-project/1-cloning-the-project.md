# Клонування проекту

Щоб зібрати бібліотеку з вихідних кодів, склонуй поточний проект у свою локальну директорію, виконавши наступну команду в терміналі (для GNU/Linux):

```
git clone https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers.git
```

Бібліотека знаходиться у типовій гілці репозиторію `main`, тому прапорець `--branch` не є обов'язковим. Якщо ж бажаєш вказати гілку явно:

```
git clone --branch main https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers.git
```

Після успішного виконання даної команди у поточній відкритій директорії повинна з'явитись нова піддиректорія `ImagesAnnotator-DataDrivers`. Отож відкрий її за допомогою команди `cd ImagesAnnotator-DataDrivers`.

Вихідні коди даної бібліотеки було виділено з програми [ImagesAnnotator](https://github.com/yuriysydor1991/ImagesAnnotator.git) - а саме з її компоненту `src/annotator-business/dbs/AnnotationsDBs`, котрий утримує JSON-базу даних проекту анотацій - щоб будь-який проект, який бажає читати чи записувати ті самі файли проектів анотацій, міг перевикористати їх замість того, щоб утримувати власну копію. Сама програма невдовзі позбудеться власної копії і споживатиме дану бібліотеку.

Зверни увагу, що експортери наборів даних тієї програми (у простий текст, YOLO і PyTorch-Vision) **не** є частиною даної бібліотеки: вони мають стати окремим власним проектом.

Коли вихідні коди на місці, переходь до розділів [Вимоги](/doc/sections/uk_UA/3-requirements/3-requirements.md) і далі [Збірка проекту](/doc/sections/uk_UA/5-project-build/5-project-build.md).

Якщо ж не маєш наміру бавитись із самою бібліотекою, а тільки потребуєш її споживати, то немає жодного обов'язку зберігати вихідні коди: сконфігуруй, збери і встанови їх один раз (див. розділ [Встановлення](/doc/sections/uk_UA/7-installing/7-installing.md)), а тоді спрямуй власний проект на встановлений CMake-пакунок.
