## Вмикання підтримки генерування DEB-пакетів з cpack

Для того щоб мати змогу згенерувати `deb`-пакет необіхдно сконфігурувати проект для підтримки команди `cpack` за допомогою змінної `ENABLE_DEB`:

```
# всередині кореневої директорії проекту 

mkdir -vp build && cd build && cmake ../ -DENABLE_DEB=ON
```

Наступним кроком буде збирання або компіляція усіх необхідних файлів які повинні входити у `deb`-пакет:

```
# всередині директорії побудови проекту

cmake --build . --target all
```

На кінець, необіхдно виконати команду `cpack` всередині директорії побудови проекту:

```
# всередині директорії побудови проекту

cpack
```

Згенерований пакет повинен згенеруватись всередині кореня директорії побудови проекту. Наприклад, якщо ім'я проекту було не зміненим і його версія `0.14.0` тоді назва пакету може виглядати наступним чином: `ImagesAnnotatorDataDrivers-0.14.0-Linux.deb`.

Пакет несе те, що встановлює проект, а саме динамічну бібліотеку `libImagesAnnotatorDataDrivers-0.14.so.0.14.0` з її символьними посиланнями, публічні заголовкові файли під `include/ImagesAnnotatorDataDrivers-0.14/` і файли CMake-пакета - усе, що потрібно виклику `find_package(ImagesAnnotatorDataDrivers-0.14 REQUIRED)` у проекті-споживачі. Жодного виконуваного файлу у ньому немає, даний проект його не будує.

Для того щоб переглянути або змінити параметри створення `deb`-пакетів необхідно відвідати файл [cmake/enablers/packagers/template-project-deb-enabler.cmake](/cmake/enablers/packagers/template-project-deb-enabler.cmake).
