## Побудова через командний рядок

Проект використовує систему побудови CMake - отож команди побудови мають бути знайомими більшості C++ розробників на планеті!

Звісно, проект спочатку потребує клонування за допомогою команди `git clone` і його коренева директорія повинна бути відкритою у терміналі або у використовуваному IDE. Після чого можна виконати наступні команди:

```
# з кореня проекту

cmake -B build -S . && cmake --build build
```

Яка у свою чергу створить директорію `build` (директорія вже додана до файлу `.gitignore`), сконфігурує проект використовуючи доступну у ОС версію системи побудови CMake (детальніше у секції [Вимоги](/doc/sections/uk_UA/3-requirements/3-requirements.md) даного документу), і на кінець побудує усі цілі, доступні у проекті.

Головним артефактом побудови є сама динамічна бібліотека, вироблена у директорії `build/src/lib`:

```
build/src/lib/libImagesAnnotatorDataDrivers-0.14.so.0.14.0    справжній двійковий файл бібліотеки
build/src/lib/libImagesAnnotatorDataDrivers-0.14.so.0         символьне посилання SONAME
build/src/lib/libImagesAnnotatorDataDrivers-0.14.so           символьне посилання для лінкера
```

Частина `ImagesAnnotatorDataDrivers-0.14` є назвою бібліотеки, виведеною з назви проекту плюс його мажорної версії, і її можна підлаштувати - див. підрозділ [Налаштування складових імені встановлюваної бібліотеки](/doc/sections/uk_UA/5-project-build/compression/5-23-customizing-library-name-segments.md).

Зверни увагу, що проект не будує **жодного виконуваного файлу**: динамічна бібліотека плюс, якщо тести були увімкнені на стадії конфігурації, двійкові файли тестів `UTEST_*` і `CTEST_*` - це усе, що тут будується. Усі три обов'язкові сторонні залежності бібліотеки (бібліотека nlohmann JSON, libcurl і zlib) увімкнені за замовчуванням, тож проста команда вище вже є достатньою для отримання повної побудови.
