## Вмикання підтримки цілі статичного аналізатора коду cppcheck

Для того щоб зробити доступною для виконання ціль статичного аналізу за допомогою `cppcheck` необхідно сконфігурувати проект з увімкненою опцією `IADD_ENABLE_CPPCHECK`:

```
# всередині кореневої директорії проекту-шаблону

mkdir -vp build && cd build && cmake ../ -DIADD_ENABLE_CPPCHECK=ON
```

І для безпосереднього виконання статичного аналізу коду необхідно викликати ціль `cppcheck` для побудови:

```
# всередині директорії побудови проекту-шаблону

cmake --build . --target cppcheck
```

Деталі цілі `cppcheck` можна переглянути і/або змінити у файлі `cmake/imagesannotator-datadrivers-cppcheck-target.cmake` системи збірки CMake.
