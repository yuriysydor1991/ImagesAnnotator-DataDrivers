# Створення форку і заміна оригінального репозиторію

Якщо маєш намір розвивати бібліотеку або підтримувати похідний від неї проект, не надсилай зміни до оригінального репозиторію - спершу створи власний форк і спрямуй свій локальний клон на нього.

Створення форку може бути виконаним через Web-панель інтерфейсу git (наприклад кнопкою **Fork** на [GitHub](https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers)).

Після створення власного репозиторію склонуй поточний проект у свою локальну директорію (див. розділ [Клонування проекту](/doc/sections/uk_UA/1-cloning-the-project/1-cloning-the-project.md)) і виконай заміну посилання оригінального репозиторію всередині кореневої директорії проекту:

```
# Заміни наступний URL на власний
git remote set-url origin https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers.git
```

Заміни посилання `https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers.git` на власний URL від свого новоствореного репозиторію проекту.

Для того щоб перевірити чи замінився URL віддаленого репозиторію (куди будуть надсилатись усі зміни) необхідно виконати наступну команду:

```
git remote -v
```

Після виконання якої у терміналі повинно висвітлитись нове посилання на новий проект.

Тепер можна скопіювати усі зміни до нового розміщення, виконуючи наступну команду:

```
git push
```

Якщо ж бажаєш зберегти доступність оригінального репозиторію для майбутніх оновлень, додай його як другий віддалений репозиторій замість того, щоб позбуватись його:

```
git remote add upstream https://github.com/yuriysydor1991/ImagesAnnotator-DataDrivers.git
git fetch upstream
```
