## Configuring the documentation install support

It's possible to enable support for the document installation by setting up the `ENABLE_DOC_DOXYGEN` and `DOXYGEN_DO_INSTALL` variables to `ON` value during the project configure stage.

```
# inside the project root directory

cmake -B build -S . -DENABLE_DOC_DOXYGEN=ON -DDOXYGEN_DO_INSTALL=ON
```

The `DOXYGEN_OUT_HTML_NAME` CMake variable will configure the documentation html directory name (passed into the `Doxyfile`). Its default value is `${PROJECT_LIBRARY_NAME}-html`, which for the untouched project means `ImagesAnnotatorDataDrivers-0.14-html`.

With both variables enabled, the generated `doc/ImagesAnnotatorDataDrivers-0.14-html` directory is installed as a whole into the `share/docs` subdirectory of the install prefix, under the `Documentation` install component:

```
# inside the project root directory

cmake --build build --target Doxygen-doc
cmake --install build --prefix /usr/local

# the documentation then lands in
# /usr/local/share/docs/ImagesAnnotatorDataDrivers-0.14-html/index.html
```

Note that the documentation has to be generated by the `Doxygen-doc` target *before* the install command is executed - the install rule only copies an already existing directory.
